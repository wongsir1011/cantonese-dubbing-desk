1. 呢個程式做乜？

將任何語言嘅 podcast 或者影片，轉成廣東話配音。

  • 音檔輸入（mp3/m4a/wav）→ 廣東話 MP3
  • 影片輸入（mp4/mov/webm）→ 廣東話配音 MP4 + 繁體中文字幕

適合處理 NotebookLM 產生嘅普通話節目，亦都做到英文、日文、韓文等等嘅內容，一律變成香港觀眾聽得舒服嘅廣東話版本。源語言喺設定入面揀（預設自動偵測）。

點運作：轉錄 → 分辨男女講者 → 譯做廣東話 → 你手動校對 → 語音合成 → 貼返落原片

整個程式喺你部機本機行，音檔冇上載去任何雲端（除咗發送去 API 服務嗰陣），金鑰只存喺你部瀏覽器。

2. 部電腦要準備乜嘢

一定要有

Python 3.8 或以上

Windows：去 python.org/downloads 下載安裝，安裝時記得勾選「Add python.exe to PATH」（呢個位好易漏，勾唔到嘅話啟動器揾唔到 Python）。

macOS：可以喺終端機行 brew install python，或者由 python.org 下載安裝檔。

安裝完開一個新嘅命令視窗（Windows 用 cmd，Mac 用 Terminal），行呢句確認：

python --version

見到 Python 3.x.x 就 OK。

有影片先需要

ffmpeg — 淨係做音檔轉換嘅話唔使裝，處理影片先要。

Windows（開一個新嘅 PowerShell 視窗）：

winget install Gyan.FFmpeg

macOS：

brew install ffmpeg

裝完關咗個舊視窗，開返一個新嘅（舊視窗食唔到新 PATH），確認：

ffmpeg -version

見到版本號就 OK。

3. 申請 API Key

三個服務，兩個必填（Azure + Google），一個選填（MiniMax）。全部有免費額度，唔使月費。

3.1 Azure Speech — 必填，免費

負責轉錄（片源語言 → 文字，並且分辨男女講者）同語音合成（廣東話文字 → 聲音）。免費層每月夠用 5 小時轉錄同 50 萬字元語音，你自己用完全夠。

要用信用卡登記，但唔會扣錢（免費層唔使畀）。

步驟

  1. 開戶：去 azure.microsoft.com/free，撳「Start free」，用 Microsoft 帳戶登入（冇就即場開）。
  2. 驗證信用卡：Azure 要求填卡確認你係真人，但只要唔升級付費層就唔會扣錢。
  3. 建立 Speech 資源： - 登入 portal.azure.com 之後，撳左上角「Create a resource」 - 搜尋「Speech」，揀「Speech」（發行者係 Microsoft），撳「Create」 - Subscription：揀你嘅 Azure subscription（通常只有一個） - Resource group：撳「Create new」，隨便改個名，例如 dubbing - Region：揀近你嘅，香港用戶建議揀 Southeast Asia（新加坡） - Name：改個獨特嘅名，例如 mydub2026（會用嚟做網址，全球唯一） - Pricing tier：撳「Change pricing tier」→ 揀「Free F0」→ Select - 撳「Review + create」→ 「Create」 - 等大約一分鐘部署完成
  4. 攞金鑰： - 撳「Go to resource」 - 左邊選單揾「Keys and Endpoint」（喺 Resource Management 分類下） - 你會見到：
    • KEY 1：一串 32 個字元嘅碼 → 呢個係 API Key
    • Location/Region：例如 southeastasia → 呢個係 Region
    • Name（頁面左上角嗰個大字）：例如 mydub2026 → 呢個係資源名稱
    • 撳 KEY 1 旁邊個複製掣

三樣嘢等陣要填：KEY 1、Region、資源名稱。全部複製落一個備忘錄先，等陣一齊貼。

3.2 Google Gemini — 必填，免費

負責翻譯（片源語言 → 廣東話口語）。免費層每分鐘 10 次、每日 250 次請求，一集 20 分鐘節目大約用 14 次，非常夠用。

唔使信用卡。

步驟

  1. 去 aistudio.google.com/apikey，用你嘅 Gmail 登入
  2. 第一次入去可能要接受條款
  3. 撳右上角「Create API key」
  4. 揀「Create API key in new project」（如果你冇 Google Cloud project）
  5. 一串 AIza... 開頭嘅金鑰會顯示出嚟，撳「Copy」

貼落備忘錄。呢條 key 之後任何時候都可以喺同一頁揾返，唔會消失。

3.3 MiniMax — 選填（想試更自然嘅粵語聲先要）

Azure 嘅粵語聲已經好穩定，日常用完全夠。但 MiniMax 有真人主持感嘅粵語聲，如果你想成品聽落更似人講，可以加。

按用量收費，一集 20 分鐘節目大約 US$0.2–0.4（大陸版價錢類似，但以人民幣計）。

MiniMax 有國際版同大陸版兩個獨立系統，可以擇一或者兩邊都填（程式入面隨時切換）：

國際版 大陸版
網址 platform.minimax.io platform.minimaxi.com
收費 美元計、要外幣信用卡 人民幣計、支持支付寶/微信
Group ID 通常唔需要 一定要填
帳戶／key 兩邊獨立，唔通用

國際版步驟

  1. 去 platform.minimax.io，撳右上角「Console」→ 電郵登入
  2. 左邊選單揾「API Keys」（有時叫「Access」），撳「Create new API key」
  3. 改個名（例如 dubbing），複製條 key
  4. Group ID（選填）：帳戶管理頁 → 基本信息，揾「GroupID」（唔係 UID）。冇顯示就唔理
  5. 增值：試用 credit 用完要去「Billing」增值

大陸版步驟

  1. 去 platform.minimaxi.com（注意係 minimaxi 有個 i），用手機號登入
  2. 完成實名認證（大陸版必要）
  3. 上方「接口密鑰」→ 新建 API Key，複製
  4. 賬戶管理 → 「基本信息」揾「GroupID」（大陸版一定要填）
  5. 充值（支付寶/微信）

貼落備忘錄：Key（+ GroupID，大陸版必要）。填設定嗰陣程式會有一個「MiniMax 地區」下拉，隨時切換。

想用真人聲（你自己或者已攞到同意嘅人）配音，而唔係機器聲？睇 8. 進階設定 → 用真人聲配音。呢個都係用 MiniMax，所以上面呢個 key 一定要先申請好。

4. 第一次啟動

  1. 將 zip 檔解壓去一個乾淨資料夾，例如： - Windows：D:\粵語配音台 - Mac：~/Documents/粵語配音台
  2. 資料夾入面應該有七個檔案： index.html serve.py launch.bat ← Windows 用呢個 launch.command ← Mac 用呢個 README.md 速查.md .gitignore
  3. 雙擊啟動器： - Windows：launch.bat - Mac：launch.command（第一次可能要先喺終端機行 chmod +x launch.command 授權）
  4. 會彈出一個黑色視窗，顯示： 粵語配音台 ────────────────────────────────────────────── 資料夾 D:\粵語配音台 應用程式 index.html （2026-XX-XX XX:XX） 影片合成 可用 ────────────────────────────────────────────── 網址 http://localhost:8000 停止 喺呢個視窗按 Ctrl+C ──────────────────────────────────────────────
  5. 瀏覽器會自動打開 http://localhost:8000，見到界面就成功

用完想關掉：喺黑色視窗按 Ctrl+C，或者直接閂咗個視窗。

⚠ 千祈唔好直接雙擊 index.html——噉樣會經 file:// 打開，冇代理，所有功能都用唔到。要經 launch 啟動器。

5. 填設定

第一次開，撳右上角「設定」，填以下欄位：

欄位 貼咩落去
Google AI Studio Key 你嘅 AIza...
Azure Speech Key 你嘅 KEY 1（32 字元）
Azure 區域 southeastasia（要細楷，冇空格）
Azure 資源名稱 你剛才改嗰個名，例如 mydub2026

其他欄位（模型、語氣、字幕字數等）留返預設。撳「儲存」。

片源語言

設定入面「片源語言」話畀程式知條片講緊咩語言。

  • 自動偵測（預設）— 送一批常見語言候選去做語言識別。唔肯定就用呢個
  • 或者直接指定：普通話、粵語、英文、日文、韓文、西班牙文、法文、德文、泰文、印尼文、越南文

知道係咩語言就直接揀，會準啲亦快啲。輸出永遠係廣東話，唔會因為源語言而變。

用 ElevenLabs Scribe v2 引擎嘅時候，佢永遠自己偵測語言，唔理呢個設定。

驗證翻譯通不通：撳「儲存」旁邊嘅「測試翻譯」。

  • ✔ 出到廣東話譯文：一切 OK，可以開始用
  • ✘ 出錯：睇下面「遇到問題點算」

想用 MiniMax 語音（選填）

國際版同大陸版可以只填一個，亦可以兩個都填備用。

  1. 設定入面對應嘅金鑰欄貼你條 key（國際版填 MiniMax 國際版；大陸版填 MiniMax 大陸版 兩欄）
  2. 「語音引擎」揀「MiniMax 官方」
  3. 「MiniMax 地區」揀國際版或者大陸版
  4. 儲存

校對頁隨便一句撳 ▶ 試聽掣，就會用 MiniMax 出聲。同一句切返 Azure 或者切另一個地區再試，直接對比。

6. 日常操作流程

主頁面拖入一個檔案（音檔或者影片），跟住六個步驟自動行：

拖檔案 → 開始轉錄 → 自動翻譯 → 校對 → 合成語音 → 下載成品

校對頁做乜

轉錄同翻譯完成後會去到校對頁，逐句顯示： - 原文（片源語言） - 譯文（廣東話） - 講者標籤：男A / 女B，撳可以單獨換 - ▶ 試聽：即時聽下呢一句廣東話點讀 - ⇅：由呢句起，之後全部男女調轉（處理 Azure 分講者錯亂）

如果整段譯文邊界有紅色（未譯）或者黃色（書面語）標籤，撳頂部「重譯有問題嘅句子」——只會動嗰啲句，其他保留。

滿意先撳「合成廣東話音檔」。

合成之後

  • 音檔：直接下載 MP3
  • 影片：合成完可以揀「內嵌字幕軌」或者「燒錄入畫面」，同時下載 SRT 字幕檔

7. 遇到問題點算

頁面頂部出現黃色警告框

自檢已經寫明問題，跟住做就得。最常見四種：

情況 解決
「你係直接開檔案」 唔好雙擊 index.html，要雙擊 launch.bat / launch.command
「serve.py 未行」 啟動器冇 run，重新雙擊
「serve.py 係舊版」 你資料夾入面有舊檔，全部刪走用新版
「未裝 ffmpeg」 只影響影片功能，音檔照用

「測試翻譯」出 ✘

睇錯誤訊息第一行：

  • 401 / 403 / API key not valid：Google key 錯，去 aistudio.google.com/apikey 重新複製
  • 429：你短時間內請求太多，等 30 秒再試
  • quota exceeded：今日 250 次已經用完，聽日再用

合成語音一路 Failed to fetch

Azure F0 免費層速率限制。設定 → 確認「Azure 定價層」揀咗「F0 免費層」，程式會自動放慢遷就。

MiniMax 認證失敗

  • 1004 / 401：API Key 錯咗，或者地區揀錯（國際版 key 唔可以打大陸版 API，反之亦然）
  • 1008：餘額不足，去對應平台（.io 或者 .minimaxi.com）增值
  • 提到 group：Group ID 唔啱。大陸版必填，返「基本信息」頁揾 GroupID（唔係 UID）

字幕溢出畫面

設定 → 調細「字幕每行字數」（16 字適合手機）

譯文偏書面語

校對頁撳「重譯有問題嘅句子」，通常撳兩次會再好啲。

影片同聲對唔上

設定 → 「聲畫對齊方式」預設「壓縮音軌」。壓到盡都仲超出就揀「延長影片」（會凍結尾格補足秒數）。

8. 進階設定

語氣選擇（設定入面）

五種： - 原汁原味（預設）：忠於原文 - 生動活潑：適合輕鬆節目 - 嚴肅專業：適合新聞、教學 - 好奇提問：適合訪談 - 溫和親切：適合輔導、健康話題

換咗語氣之後校對頁撳「用呢個語氣重譯」，唔會用新嘅轉錄額度。

Google Chirp 3: HD — 粵語音色最多（選填）

yue-HK 有 30 把粵語聲，男女都有，係目前粵語音色最多嘅一家。

用返你已經填咗嘅 Google AI Studio Key，但條 key 要另外授權，去 Cloud Console 做兩件事：

  1. APIs & Services → Library → 搜 Cloud Text-to-Speech API → Enable
  2. APIs & Services → Credentials → 撳你條 key → API restrictions

⚠ 第 2 步最易中伏。如果你揀咗「Restrict key」，一定要同時勾住 Generative Language API（翻譯同 Gemini 轉錄用）同 Cloud Text-to-Speech API。淨係加新嗰個會踢走舊嗰個，翻譯就會靜靜壞。

做完之後：設定 → 「語音引擎」揀「Google Chirp 3: HD」→ 撳「拎返可用粵語聲」。

  • Chirp 3: HD 唔支援 SSML，語氣嘅音高唔生效，語速有效
  • yue-HK 仲係 Preview，音色同定價都可能變
  • 按量收費，冇免費層

男女聲揀選

Azure： - 男：WanLung 雲龍 / WanShan 雲山 - 女：HiuMaan 曉曼 / HiuGaai 曉佳

MiniMax：預設官方粵語主持聲。ID 入面個括號係全形（（M) （F)），係官方原樣，唔好改半形。

用真人聲配音（聲音克隆）

預設嘅粵語聲（Azure 或者 MiniMax 官方主持聲）都係機器模擬。如果想用某個真人嘅聲（你自己、同事、或者已攞到當事人同意嘅人）嚟配音，MiniMax 有「聲音克隆」功能：上載一段呢個人講嘢嘅錄音，幾十秒之後就可以攞到一把聽落似佢嘅聲，之後配音就用呢把聲代替機器聲。

⚠️ 先決條件（一定要睇）

  • 要用 MiniMax 做語音引擎（設定 → 語音引擎揀「MiniMax 官方」），呢個功能唔支援 Azure 或 GLM
  • 一定要先有 MiniMax API Key，做法見上面 3.3 MiniMax
  • 同意問題你要自己把關：程式會要求你剔一個確認格「已經攞到把聲主人嘅同意」，但呢個純粹提醒，唔係法律保障。用你自己把聲冇問題；用第二個人嘅聲，一定要事先講清楚、攞到佢哋首肯，先好上載。唔好用嚟扮任何冇同意嘅人，尤其係要拎去公開發佈嘅內容
  • 克隆出嚟嘅聲唔係永久保存：7 日內冇用嚟合成過語音就會被系統自動刪走。即係話你唔可以「克隆一次，擺一年後先用」——要就快啲用，或者接受每次專案要重新克隆

準備錄音

  1. 揀一段呢個人講嘢嘅清晰錄音：單一講者、環境安靜、冇背景音樂或者回音，唔好用電話免提咁遠嘅收音
  2. 格式要係 mp3、m4a 或 wav
  3. 長度要 10 秒至 5 分鐘（唔使好長，一分鐘左右已經夠；愈清晰通常克隆得愈似）
  4. 檔案唔可以超過 20MB

冇現成錄音？用手機錄音 app 錄一分鐘自然講嘢就得，唔使錄稿（讀新聞腔會令克隆出嚟嘅聲太生硬）。

步驟

  1. 撳右上「設定」→ 語音引擎揀 「MiniMax 官方」，展開之後捲到最底，會見到「聲音克隆 — 用真人聲配音」一區
  2. 剔低「我確認已經攞到呢把聲主人嘅同意」
  3. 撳「Choose File」揀返準備好嘅錄音檔案
  4. 「呢把聲嘅名稱（voice ID）」入一個名，淨係可以用英文字母／數字／底線，一定要英文字母開頭，例如 andrew_v1、colleague_wong（呢個名之後用嚟喺男聲／女聲揀返呢把聲，改得有意義啲方便自己記）
  5. （可選）如果想再準確啲，可以另外上載一段短過 8 秒嘅樣本音檔，並喺旁邊填返呢段樣本嘅逐字稿（一字不差，句尾要有標點）——呢步淨係優化相似度，唔加都克隆得到
  6. （可選）「試聽文字」入一句嘢，克隆完成會即刻用呢把新聲讀呢句畀你聽，方便即場判斷似唔似
  7. 撳「克隆呢把聲」，等大約十幾秒到半分鐘
  8. 成功之後，下面會多一行你嘅聲：🗣 andrew_v1（克隆聲），有幾個掣：
    • ▶ 試聽：如果第 6 步填咗試聽文字，撳呢個聽返個效果
    • 用做男聲／用做女聲：撳一下就將呢把聲指派做配音嘅男聲或者女聲，同揀官方音色一樣做法
    • 刪除：唔要呢把聲就撳呢個，MiniMax 帳戶入面都會刪走（呢步冇得返轉頭）

之後撳「儲存」，拖檔開始轉錄配音，男聲／女聲就會用返你剛克隆嘅聲，唔再係機器聲。

留意事項

  • 7 日內冇用過會被刪：如果你隔一排先再用返呢個 voice ID 去合成，可能已經俾系統自動清走，要重新克隆一次
  • 粵語咬字未必完美：呢個係普通話／英文為主嘅克隆模型讀廣東話，聲底似唔似真人係一回事，讀粵語嘅咬字準唔準又係另一回事，同官方粵語主持聲比，可能有落差，建議先用「試聽文字」聽下先決定用唔用
  • voice ID 唔可以重複用：如果個名已經俾你（或者第啲人喺呢個帳戶）用過，克隆會失敗，換個新名再試
  • 想管理已經克隆嘅聲（睇下有邊幾把、刪走舊嘅），可以喺「拎返可用音色清單」度睇到，粵語相關嘅聲同克隆聲都會用 🗣 標記排前
