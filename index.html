Credentials

API 金鑰

全部只存喺你部機嘅 localStorage，唔會傳去任何第三方。

要用本機伺服器開呢個檔案，直接雙擊 file:// 會被瀏覽器擋住 API 呼叫。
將 serve.py 同呢個 HTML 擺埋一齊，行 python3 serve.py，再開 localhost:8000。
serve.py 同時做 API 代理，可以繞過各家轉錄／語音服務嘅 CORS 限制。
區域要同資源頁「位置/區域」欄一模一樣，例如 southeastasia。 對唔上會直接 401。
注意：呢三個欄就算你轉錄用第二個引擎都要填 —— Azure 同時係預設嘅語音合成引擎。
預設係 Azure 官方三把 zh-HK 粵語聲。撳上面粒掣會由 Azure 直接查你帳戶實際攞到嘅粵語聲（有時會有新增嘅 HD 聲，例如 Achird HK）。
GLM-TTS 內建音色（例如 tongtong）。官方文檔冇列明粵語支援，多數會用普通話腔讀廣東話字，請試聽再決定。
預設係官方粵語主持聲（ID 入面個括號係全形，係官方原樣，唔好改半形）。撳上面粒掣可以睇返你個帳戶實際用得嘅音色，包括粵語同其他方言標籤。校對頁每句嘅 ▶ 可以即時試聽。
